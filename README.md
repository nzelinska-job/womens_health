# Women's Health - Menstrual Cycle Predictor

Machine learning project for predicting menstrual cycles and women's health insights.

## Installation
``` venv
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
```

```bash
pip install -r requirements.txt
pip install kagglehub pyyaml
```

## Usage

```bash
python scripts/generate_synthetic_data.py
python scripts/train_model.py
python scripts/make_predictions.py
```
